+## Directory Inference
+
+For batch inference, create a single mounted handoff folder with an `input`
+directory containing at least one `.tif` or `.tiff`:
+
+```text
+input-output/
+  input/
+    image-a.tif
+    image-b.tif
+  output/
+```
+
+Run the container with that folder mounted at `/io`:
+
+```bash
+mkdir -p input-output/output
+docker run --rm --gpus all --ipc=host \
+  -v "$PWD/runs:/workspace/runs" \
+  -v "$PWD/input-output:/io" \
+  pix2poly:p2p infer-dir
+```
+
+For each input image, `infer-dir` writes these files under `/io/output`:
+
+- `<image>.gpkg`
+- `<image>_visualization.png`
+- `<image>_tile-visualization.png`
+- `<image>_bitmap-visualization.png`
+
+GeoPackage geometries are transformed from model pixel coordinates through the
+source GeoTIFF affine transform and CRS. If the input image is not georeferenced,
+the GeoPackage falls back to pixel coordinates with no CRS.
+
